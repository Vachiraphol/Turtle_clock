# Turtle Clock

โปรเจกต์นาฬิกาดิจิทัลบนไมโครคอนโทรลเลอร์ ESP32 พัฒนาด้วยภาษา C และ ESP-IDF แสดงเวลาและวันที่บนจอ OLED, ซิงค์เวลาผ่าน Wi-Fi กับเซิร์ฟเวอร์ NTP และมีเมนูสำหรับปรับเขตเวลาและตั้งวัน/เวลาด้วยปุ่มกด

## ความสามารถ

- แสดงเวลาและวันที่บนจอ OLED ขนาด 128×64
- ซิงค์เวลากับ `pool.ntp.org` ผ่าน Wi-Fi
- ปรับเขตเวลาได้ตั้งแต่ UTC−12 ถึง UTC+14
- ตั้งชั่วโมง นาที วินาที ปี เดือน และวันด้วยตนเอง
- ตรวจสอบวันที่ รวมถึงปีอธิกสุรทิน ก่อนบันทึก
- ใช้ปุ่ม UP, DOWN และ SELECT ควบคุมเมนู

## อุปกรณ์และการต่อสาย

โค้ดกำหนดขาและอุปกรณ์ไว้ดังนี้:

| อุปกรณ์ | ขา ESP32 / ค่า |
| --- | --- |
| OLED แบบ I2C ที่รองรับคำสั่ง SSD1306, 128×64 | SDA: GPIO 21, SCL: GPIO 22 |
| ที่อยู่ I2C ของ OLED | `0x3C` |
| ปุ่ม UP | GPIO 4 |
| ปุ่ม DOWN | GPIO 16 |
| ปุ่ม SELECT | GPIO 17 |

ขาปุ่มเปิดใช้ internal pull-up ดังนั้นให้ต่อปุ่มระหว่าง GPIO ที่ระบุและ GND

## การใช้งาน

1. ติดตั้งและเปิดใช้งานสภาพแวดล้อม ESP-IDF สำหรับ ESP32
2. ใน `ESP32_Digital_Clock/main/main.c` เปลี่ยน `WIFI_NAME` และ `WIFI_PASSWORD` เป็นชื่อและรหัสผ่าน Wi-Fi ที่อุปกรณ์เชื่อมต่อได้
3. เข้าโฟลเดอร์โปรเจกต์:

   ```sh
   cd ESP32_Digital_Clock
   ```

4. ตั้งเป้าหมายและคอมไพล์:

   ```sh
   idf.py set-target esp32
   idf.py build
   ```

5. เชื่อมต่อบอร์ด แล้วแฟลชและเปิด serial monitor (แทน `PORT` ด้วยพอร์ตของบอร์ด เช่น `COM3`):

   ```sh
   idf.py -p PORT flash monitor
   ```

เมื่อเริ่มทำงาน อุปกรณ์จะเชื่อมต่อ Wi-Fi และรอการซิงค์เวลากับ NTP จากนั้นจะแสดงนาฬิกาและวันที่บนจอ

### การควบคุมเมนู

- กด SELECT จากหน้าปกติเพื่อเข้าเมนูตั้งค่า
- ใช้ UP และ DOWN เพื่อปรับค่าที่เลือก
- กด SELECT เพื่อเลื่อนไปยังรายการถัดไปตามลำดับ: เขตเวลา, ชั่วโมง, นาที, วินาที, ปี, เดือน และวัน
- กด SELECT ที่รายการวันเพื่อบันทึกและกลับหน้าปกติ หากวันที่ถูกต้อง
- หากวันที่ไม่ถูกต้อง เช่น 31 กุมภาพันธ์ เมนูจะยังอยู่ที่รายการวันจนกว่าจะแก้ไข

```text
Turtle_clock/
├── README.md
└── ESP32_Digital_Clock/
    ├── CMakeLists.txt
    └── main/
        ├── main.c              # จุดเริ่มต้นและลูปหลักของแอป
        ├── clock.c / clock.h   # สถานะและลอจิกเมนูตั้งค่า
        ├── display.c / display.h # วาดหน้าจอและสื่อสารกับ OLED ผ่าน I2C
        ├── input.c / input.h   # อ่านปุ่มและ debounce
        ├── time_settings.c / time_settings.h # Wi-Fi, NTP และการจัดการเวลา
        ├── timezone.c / timezone.h # ตั้งค่าเขตเวลา
        └── CMakeLists.txt      # รายการ source files ของ component
```
